# AI Engineer / Python Developer Portfolio

A responsive, buildless portfolio frame using the requested midnight forest (#091310), soft ivory (#ECFDF5), sage gray (#8A9A90), warm brass (#E5C158), and forest surface (#11221B) palette.

## Preview

Run `node server.cjs` in this folder, then visit http://127.0.0.1:4173.

## Personalize

Edit `dist/index.html` for your name, biography, toolkit, projects, and contact details. Example projects are explicitly marked as concepts. Their modal content is in `dist/script.js`. Replace the contact button handler with your real contact destination when available.

Theme values and responsive layouts are in `dist/styles.css`. Google Fonts are optional; system fallbacks are configured.

The site has no build step or runtime dependencies. Serve the `dist` directory with any static host.
